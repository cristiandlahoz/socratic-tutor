1. PURPOSE                                                *history-purpose*

Socratic Tutor stores each conversation as one Spring AI Session event log.

The same stored log is read in different ways:

  - the model needs compacted active context
  - the chat UI needs the real transcript

Compaction archives older real events and adds synthetic summary events. The UI
must hide synthetic events, while the model should use them.

===============================================================================
2. ONE EVENT LOG                                        *history-event-log*

Each chat request passes the conversation id as the Spring AI session id:

>
    .param(SessionMemoryAdvisor.SESSION_ID_CONTEXT_KEY, conversationId.toString())
    .param(SessionMemoryAdvisor.USER_ID_CONTEXT_KEY, groupClassMemberId.toString())
<

The stored event log can contain real, archived, and synthetic events:

>
  SPRING AI SESSION EVENT LOG

  entry:   0       1       2       3       4       5       6       7
         +-------+-------+-------+-------+-------+-------+-------+-------+
         | User  | Asst  | User  | Asst  | Synth | Synth | User  | Asst  |
         | real  | real  | real  | real  | User  | Asst  | real  | real  |
         +-------+-------+-------+-------+-------+-------+-------+-------+
          `-------------------+-------------------' `-------+-------' `---+---'
                    archived real history              summary      active real
<

Archived does not mean deleted. Synthetic does not mean user-visible.

===============================================================================
3. SYNTHETIC EVENTS                                    *history-synthetic*

Synthetic events are generated by the application/framework, not by the student
or normal tutor response path.

The compaction strategy marks them with metadata:

>
    .metadata(SessionEvent.METADATA_SYNTHETIC, true)
    .metadata(SessionEvent.METADATA_COMPACTION_SOURCE, STRATEGY_NAME)
<

Spring AI exposes this as:

>
    event.isSynthetic()
<

Synthetic compaction turn:

>
  +------------------------------+   +------------------------------+
  | Synthetic UserMessage        |   | Synthetic AssistantMessage   |
  +------------------------------+   +------------------------------+
  | Resume la conversación de    |   | Generated summary of older   |
  | tutoría hasta ahora.         |   | tutoring context.            |
  +------------------------------+   +------------------------------+
<

This turn belongs in model memory. It does not belong in the student-facing chat
transcript.

===============================================================================
4. MODEL CONTEXT FILTER                             *history-model-filter*

The model uses active context. This is configured in `AIConfig`:

>
    var sessionMemoryAdvisor = SessionMemoryAdvisor.builder(sessionService)
            .eventFilter(EventFilter.active())
            .compactionTrigger(...)
            .compactionStrategy(...)
            .build();
<

`EventFilter.active()` excludes archived events.

After compaction, the model sees:

>
  MODEL CONTEXT

      synthetic memory             recent real turns         current prompt
  .-------------------.        .----------------------.     .--------------.
  |                   |        |                      |     |              |
  v                   v        v                      v     v              v

  +-----------+-----------+  +---------+---------+  +------------------------+
  | Synth U   | Synth A   |  | User 4  | Asst 5  |  | Current UserMessage    |
  +-----------+-----------+  +---------+---------+  +------------------------+
  | shadow    | summary   |  | real    | real    |  | just submitted         |
  +-----------+-----------+  +---------+---------+  +------------------------+
<

The archived old events are not sent directly to the model.

===============================================================================
5. UI DISPLAY FILTER                                  *history-ui-filter*

The UI uses a display-specific filter in `ConversationService`:

>
    private static final EventFilter DISPLAY_HISTORY_FILTER = EventFilter.builder()
            .messageTypes(Set.of(MessageType.USER, MessageType.ASSISTANT))
            .excludeSynthetic(true)
            .build();
<

The key line is:

>
    .excludeSynthetic(true)
<

The display query then applies additional stream filters:

>
    sessionService.getEvents(conversationId.toString(), DISPLAY_HISTORY_FILTER)
            .stream()
            .filter(SessionEvent::isRootEvent)
            .filter(event -> !event.isSynthetic())
            .filter(event -> !event.hasToolCalls())
            .filter(event -> event.getMessage().getText() != null)
            .filter(event -> !event.getMessage().getText().isBlank())
            .map(this::toConversationMessage)
            .toList();
<

The UI sees the real transcript:

>
  CHAT UI TRANSCRIPT

  entry:   0       1       2       3       6       7
         +-------+-------+-------+-------+-------+-------+
         | User  | Asst  | User  | Asst  | User  | Asst  |
         | real  | real  | real  | real  | real  | real  |
         +-------+-------+-------+-------+-------+-------+
          `-------------------+-------------------' `---+---'
                    archived but still real        recent active real
<

The UI excludes:

>
  - synthetic compaction summary messages
  - tool calls
  - tool responses
  - blank messages
  - non-root branch events
<

===============================================================================
6. SIDE-BY-SIDE                                      *history-side-by-side*

>
  +---------------------------+-----------------------------------------------+
  | Consumer                  | What it asks                                  |
  +---------------------------+-----------------------------------------------+
  | Model context             | What should the LLM know right now?          |
  | Chat UI transcript        | What real messages should the student see?  |
  | Compaction status         | Has anything been archived?                 |
  +---------------------------+-----------------------------------------------+

  +---------------------------+-----------------------------------------------+
  | Consumer                  | Filter                                        |
  +---------------------------+-----------------------------------------------+
  | Model context             | EventFilter.active()                         |
  | Chat UI transcript        | messageTypes(USER, ASSISTANT)                |
  |                           | + excludeSynthetic(true)                     |
  |                           | + stream filters                             |
  | Compaction status         | EventFilter.all()                            |
  +---------------------------+-----------------------------------------------+

  +---------------------------+-----------------------------------------------+
  | Consumer                  | Result                                        |
  +---------------------------+-----------------------------------------------+
  | Model context             | synthetic summary + recent active events     |
  | Chat UI transcript        | full real user/assistant transcript          |
  | Compaction status         | can detect archived events                   |
  +---------------------------+-----------------------------------------------+
<

7. MANUAL EXAMPLES                                    *history-examples*

Filter synthetic events manually:

>
    var realEvents = events.stream()
            .filter(event -> !event.isSynthetic())
            .toList();
<

Filter synthetic events with EventFilter:

>
    var filter = EventFilter.builder()
            .excludeSynthetic(true)
            .build();

    var displayEvents = sessionService.getEvents(sessionId, filter);
<

Show only real user and assistant messages:

>
    var filter = EventFilter.builder()
            .messageTypes(Set.of(MessageType.USER, MessageType.ASSISTANT))
            .excludeSynthetic(true)
            .build();
<

Detect whether a conversation has been compacted:

>
    var compacted = sessionService.getEvents(sessionId, EventFilter.all())
            .stream()
            .anyMatch(SessionEvent::isArchived);
<

===============================================================================
8. MENTAL MODEL                                  *history-mental-model*

One event log, two projections:

>
                    +------------------------------+
                    | Spring AI Session Event Log  |
                    | real + archived + synthetic  |
                    +---------------+--------------+
                                    |
          +-------------------------+-------------------------+
          |                                                   |
          v                                                   v
+------------------------------+          +------------------------------+
| MODEL PROJECTION             |          | UI PROJECTION                |
| EventFilter.active()         |          | excludeSynthetic(true)       |
+--------------+---------------+          +--------------+---------------+
               |                                         |
               v                                         v
+------------------------------+          +------------------------------+
| Synthetic summary            |          | Real transcript              |
| + recent active real events  |          | archived + active real       |
+------------------------------+          +------------------------------+
<

The model memory is compacted. The student's visible transcript remains real.
