# Socratic LoRA Fine-tune Plan

## Goal

Fine-tune LLaMA 3.1 8B with LoRA to behave as a Socratic tutor for programming courses (C language), using real professor-student dialogues as seed data.

**Framework:** Unsloth  
**Deployment:** Chat API  
**Language:** Spanish  

---

## Dataset Format

### Final format: ShareGPT → HuggingFace Chat Template

```json
{
  "conversations": [
    {
      "role": "system",
      "content": "Eres un tutor socrático de programación. Tu objetivo no es dar respuestas directas, sino guiar al estudiante mediante preguntas que lo lleven a descubrir el concepto por sí mismo. Nunca reveles la solución completa de inmediato. Usa ejemplos del mundo real antes de introducir código."
    },
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ]
}
```

**Final file:** `.jsonl` (one conversation per line)

### Speaker normalization rules

| Raw tag | Normalized role |
|---|---|
| `Profesor` / `Profesor Responde` / `Profesor pregunta` | `assistant` |
| `Estudiante` / `Estudiante Responde` | `user` |
| `Estudiantes` (group response) | `user` (collapsed into single turn) |

### Code blocks
Inline code in professor turns → wrapped in markdown fences inside the assistant turn content.

### Multi-question turns
Professor turns with multiple questions → kept as one assistant turn (do not split).

---

## Pipeline: 3 Stages

### Stage 1 — Parse real dialogues
- Input: raw `.txt` dialogue files
- Output: structured intermediate JSON with normalized speaker tags
- Tool: Python parser script (`parse_dialogue.py`)

### Stage 2 — Generate synthetic variants
- Input: structured JSON from Stage 1
- Tool: GPT-4 / Claude generation prompt (`generate_variants_prompt.md`)
- Target: 200–500 training examples from ~3 real dialogues
- Variation axes:
  - Different C topics (for loops, arrays, pointers, functions, structs)
  - Different student error patterns (wrong answers professor redirects)
  - Different student understanding levels (beginner, intermediate)

### Stage 3 — Convert to Unsloth-ready JSONL
- Input: all structured conversations (real + synthetic)
- Output: `dataset.jsonl` with HuggingFace chat template format
- Tool: conversion script (`to_jsonl.py`)
